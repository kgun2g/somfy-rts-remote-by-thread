⚡ 전원 정책 + 절전 (v3.3)

SED (Sleepy End Device) 절전 메커니즘: Thread MTD 가 부모 노드에 5초마다 data poll 송신. 부모 노드는 Matter 명령을 큐에 저장 후 다음 poll 시 전달. CPU 는 5초 중 99% 이상 light sleep 상태. 수신 시 Thread interrupt 가 CPU wake → Matter callback → 블라인드 동작.

CONFIG_FREERTOS_IDLE_TIME_BEFORE_SLEEP=3      # 3 tick 후 sleep

CONFIG_ICD_FAST_POLL_INTERVAL_MS=200          # 활성 시 200ms
CONFIG_ICD_ACTIVE_MODE_INTERVAL_MS=300        # 명령 후 300ms 활성 유지

SmartThings 명령 wake

Sleep / 화면보호기 중 SmartThings 명령 수신 시:

  1. Thread SED slow poll (5s) 으로 명령 도달
  2. _exit_sleep() / _exit_screensaver() → OLED 패널 ON, 활성 모드 복귀
  3. oled_ui_notify_action_start() → 해당 모션 (UP/DN/STOP/PROG) 표시 2.5초
  4. RF 큐로 송신 (등록된 endpoint 만)

📋 OLED 화면 회전

디바이스를 거꾸로 들고 사용하는 경우를 위해 OLED 표시가 자동으로 180° 회전됩니다.

  • 구현: oled_ui.c의 _fb_flush() 내부에서 매 프레임 (50ms, 20fps) 변환
  • 변환 = 페이지 역순 + 컬럼 역순 + 8비트 역순 (총 360 byte 처리, <50µs CPU)
  • 비활성화: #define OLED_ROTATE_180 0 후 재빌드

🔧 조립 주의사항 (v2.0)

  • CC1101은 3.3V 전용 — 5V 연결 시 즉시 파손됩니다.
  • CC1101 핀맵 (네이티브 FSPI): SCK=IO6, MOSI=IO7, MISO=IO2, CSN=IO4. PCF8574 SDA=IO19, SCL=IO18 (bit-bang).
  • 외부 풀업 필수:
    • PCF8574 SDA (IO19) ↔ +3V3: 4.7kΩ
    • PCF8574 SCL (IO18) ↔ +3V3: 4.7kΩ
    • PCF8574 ~INT (IO17) ↔ +3V3: 10kΩ ★ v2.0 신규
  • PCF8574 A0/A1/A2 를 모두 GND에 연결해야 I2C 주소가 0x20 이 됩니다.
  • OLED는 HP I2C0 (IO0/IO1, 보드 내장), PCF8574 는 software bit-bang (IO18/IO19) — 핀 충돌 없음.
  • v2.0 에서 LP_I2C0 는 사용 안 함 (LP_GPIO6/7 핀 제약 해제 → 라우팅 자유도 ↑).
  • 각 VCC 핀 근처에 100nF 디커플링 캐패시터를 배치하면 노이즈가 줄어듭니다.
  • 이 펌웨어는 Matter over Thread (802.15.4) — WiFi 미사용. Thread Border Router(SmartThings Hub v3+/Apple TV 4K/Nest Hub 2nd 등)가 필요합니다.
  • PCB 설계 파일: kicad/somfy_blinds[_v|_h|_v2|_h2].kicad_* 5종.
  • v2.0 적용 스크립트: kicad/_apply_v2_0_sch_rewire.py (스키매틱) + _apply_v2_0_pcb_nets.py (PCB).
  • 발주용 거버: kicad/gerber/somfy_blinds*.zip — v2.0 재라우팅 후 재생성 필요.
