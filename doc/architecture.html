🔀 빌드타임 변형 조합 (board_select.h ← build.ps1)

보드 헤더를 안 고치고 한 보드에서 PCF·로터리·OLED 변형을 빌드 시 고른다. 안 주면 보드 기본값(바이너리 동일). build.ps1 가 -D BOARD_OVR_* 로 주입 → board_select.h 가 보드 기본을 덮는다.

옵션값덮는 매크로효과
-Pcf8574 / 8575BOARD_HAS_LR_BUTTONS8575 = 좌/우 버튼(P10/P11) 추가 · read/write 2바이트
-Rotaryec11 / ec05BOARD_ROT_HALF_STEPec05 = half-step 그레이코드 LUT 누산 디코더
-Oled72x40 / 128x64 / 64x128BOARD_OLED_WIDTH/HEIGHT해상도 → 렌더러 자동 선택(아래). ※ CONFIG_OFFSETX 동반 조정(72x40=28 / 그외=0)
-Rotate0 / 180 / m0 / m180OLED_ROTATE_180 + OLED_FLIP_X회전 · 좌우반전(m=mirror). sdkconfig 무관, 완전 자동
변형 태그 BOARD_HW_VARIANT_STR = <pcf>.<enc>.<oled> (예 8574.ec05.128x64r0). Matter OTA 는 VID/PID + 버전만 매칭하므로, 변형을 SoftwareVersionString · .ota 파일명에 실어 교차 설치를 막는다(EC11/EC05 · 8574/8575 · OLED 는 전기적 자동감지 불가 → 이미지 식별자로 구분).

⚙️ 보드별 펌웨어 기능 차이 (ESP32-H2 메모리 제약)

⚠ ESP32-H2 는 가용 RAM ~145 KB — OpenThread FTD + Matter 가 free heap 을 거의 소진한다(BLE 커미셔닝 중 free ~2.5 KB). 그래서 H2 는 기능을 빼서가 아니라 메모리에 맞춰 아래처럼 축소·단순화한다(C6 두 보드는 RAM 여유로 제약 없음).

🔑 블록 ALL 주소 체계 & 롤링코드

주소 = F0 · [중간: 채널 등차] · [하위: 보드 ID]  (24비트, eFuse 팩토리 MAC → FNV-1a 결정적 산출 · blind_manager.c _derive_addresses):

요소규칙
상위 바이트0xF0 고정 (전 보드 공통)
중간 바이트 (블록 base)(eFuse_hash >> 8) % 0x27 → 등차 최소항 0~0x26 (carry 없음)
하위 바이트eFuse_hash & 0xFF (보드 고유 ID · 블록별 salt (g+1)×0x9E3779B1)
채널 ibase + i × 0x2700 (중간바이트 +0x27 등차)
ALLbase + 4 × 0x2700 (채널 등차의 다음 항)

4채널 = 1블록(채널 4 + 전용 ALL 1). BLIND_BLOCK_COUNT = ceil(채널/4) → H2 1블록(ALL1), C6 2블록(ALL1·ALL2), 9채널 3블록. ALL 명령 시 모든 블록의 ALL 을 차례로 송신, 채널 endpoint 들을 한꺼번에 position 갱신.

롤링코드는 전용 rollcode NVS 파티션에 채널(rolling[]) + 블록 ALL(all_rolling[]) 을 모두 보존 → Matter factory reset 후에도 복원(역행 방지). ALL 은 PROG 등록 절차가 없어(모터 내부 인식) 롤링코드 영속이 특히 중요하다.
🔑 페어링 코드(discriminator/passcode)도 같은 eFuse MAC 에서 산출(efuse_commissionable.cpp, custom CommissionableDataProvider) → 기기마다 다른 QR/PIN, fctry 플래시 불필요. 여러 대 동시 페어링도 BLE discriminator 충돌 없음(실측 disc gnpe 3327 · xiao 4032 · h2 2687). CONFIG_CUSTOM_COMMISSIONABLE_DATA_PROVIDER=y, DAC provider 는 별개 유지.

🌐 Matter 엔드포인트 구조

Bridge (C6 — 독립 타일)

EP0 Root (Basic Info: NLB / Somfy RTS Thread · Time Sync)
└ Aggregator
  ├ Bridged WindowCovering #1 (Blind 1)
  ├ … #8
→ SmartThings / Apple / Google 기기 8개

composed (H2 — 1기기 다중 EP)

EP0 Root (Basic Info)
├ EP1 WindowCovering (Blind 1)
├ EP2 · EP3
→ Apple / Google 3개 · SmartThings 는 custom driver 로 1카드 3블라인드

WindowCovering features: Lift + Tilt + PositionAware. Lift % ↔ Somfy UP/DOWN, Tilt 슬라이더 → 7단계 step burst, STOP → MY. ALL 에서는 PROG 차단(단일 블라인드 절차).
